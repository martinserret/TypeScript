3RD PARTY LIBRAIRIES & TYPESCRIPT
------------------------------------------
librairie use in this example:
- lodash: library that provides tons of helper methods that help you interact with objects, arrays, change the structure of arrays and objects and lot of useful utility functionalities. => npm i --save lodash


Problem using Javascript librairies with Typescript: 
  - some Javascript librairies are not written with Typescript in mind and are Javascript-only.
Solution:
  - typically when you're using a Javascript library in a Typescript project, you'll install an extra library that contains the type definitions (in our example @types/lodash).
  - @types repository refers the DefinitelyTyped repository (https://github.com/DefinitelyTyped/DefinitelyTyped) which maintains a huge number of type definitions for all kinds of librairies.
